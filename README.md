# Just Note

Just Note is a small, calming space to write things down. Create notes, organize them into folders, and keep track of when you want to work on them.

## Features

- Create, edit, search, and delete notes
- Organize notes into custom folders, or leave them unfiled
- Mark notes as complete
- Add start and optional finish dates and times
- See word and character counts while writing
- Automatically save notes in your browser
- Responsive layout for desktop and mobile
- Web app manifest and app icons for supported installable browsers

## Getting started

No dependencies or build step are required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

For local development, you can also serve the project directory with any static web server.

## Publish with GitHub Pages

1. Push the project files to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the branch you want to publish and the `/ (root)` folder, then save.
5. Once GitHub Pages has finished deploying, open the URL shown in the Pages settings.

The site is a static web app, so it does not need a backend or build workflow.

## Data and privacy

Notes, folders, and the optional profile name are stored in the browser's local storage on the current device. They are not uploaded or synchronized to GitHub or other devices. Clearing the browser's site data will remove them, so export or copy anything you need to keep before clearing it.

## Project files

- `index.html` — app interface, styles, and behavior
- `manifest.webmanifest` — web app metadata
- `icon-192.png`, `icon-512.png`, `icon-180.png`, `favicon.svg` — app and browser icons
